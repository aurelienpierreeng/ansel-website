**Lukas** — 2023-04-05

Hey Marco,

by default **R** will be the shortcut for **reject**. You can find all the shortcuts via *Help \> Table of key shortcuts*

If you want to change it, you can do so in *Edit \> Preferences \> Shortcuts*. However you need to search for *rating* in the search action list as reject is listed as an element(?) of rating. You will end up in the section V*iews \> Thumbtable \> Rating*
