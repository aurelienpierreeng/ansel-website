*Posted by **Alphonse PHILIPPE** on 2024-03-12.*

Bonjour,

Je débute avec Ansel.

J'arrive bien à importer des photos. Je vois les photos importées dans le bandeau du bas.

Mais aucun nom ni extension n'est affiché. Apparemment aucune option pour le faire. Il faut ouvrir la photo pour le nom avec l'extension dans les EXIF.

Y a-t-il un moyen d'afficher le nom avec l'extension dans le bandeau du bas ?

Merci

A. Philippe

## Replies

**Aurélien Pierre** — 2024-03-15

Bonjour,

le bandeau des miniatures du bas fournit un accès rapide aux photos. En raison de l'espace limité et de la hauteur flexible, il n'y a aucune garantie qu'un nom de fichier puisse rentrer en entier. Les manipulations et visualisation de fichiers sont réservées à la table lumineuse.

---

**Alphonse PHILIPPE** — 2024-03-17

Bonjour,

J'ai progressé un peu dans l'utilisation d'Ansel.

D'accord pour votre réponse concernant le bandeau du bas dans la Chambre noire.

Mais dans la Table lumineuse, le nom de la photo, avec l'extension, doit être affiché. Le nom est le minimum requis pour identifier une photo. Il devrait donc être affiché de base, avec une possibilité d'ajouter d'autres informations.

Je ne connais pas de logiciel dont la table lumineuse n'affiche pas le nom des photos.

Si cela n'est pas possible dans la version actuelle, considérez ce message comme une demande d'amélioration.

Merci

Alphonse PHILIPPE
