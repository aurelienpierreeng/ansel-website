{{- /* param-table: a borderless listing of menu entries, options or parameters. Write data rows only -- no header row, no delimiter row. Put the entry name (and its shortcut, if any) first, then wrap the explanation in a bare
to indent it underneath: {{< param-table >}} | **Close path** (or Enter)
Closes the outline.
| | **Done shape creation** (or Escape)
Leaves creation mode.
| {{< /param-table >}} A leading column carries the submenu an entry belongs to, when it has one: | **Operation** | **Invert**
Inverts the polarity.
| | | **Union**
How shapes combine.
| Markdown needs a header row to recognise a table, so one is generated here and then stripped from the output: the theme paints with `table-dark`, which would show up as an empty dark bar. Consecutive blocks butt against each other with no gap, so one menu can be split into several tables (top level vs. submenu) and still read as a single listing. `margin-left` indents the whole block by any CSS length, to nest a listing under the sentence or the entry it belongs to: {{< param-table margin-left="2rem" >}} A trailing cell may hold an illustration instead of text, as a Markdown image -- the `figure` shortcode cannot be used here, its output spans several lines and breaks the table row. `image-height` then sets a uniform height for every picture in the block (any CSS length); left out, each one fills the column: {{< param-table image-height="9rem" >}} | **Union**
Adds the shape.
| ![](union.jpg "union result") | {{< /param-table >}} Unlike the theme's `table` shortcode, this renders through Page.RenderString rather than `markdownify`, which keeps the page context alive so relative `.md` links resolve instead of collapsing to the site root. */ -}} {{- $p := .Page -}} {{- /* Optional uniform height for the illustrations, any CSS length. */ -}} {{- $imgHeight := .Get "image-height" -}} {{- /* Optional left margin for the whole block, any CSS length. */ -}} {{- $marginLeft := .Get "margin-left" -}} {{- $styles := slice -}} {{- with $imgHeight -}} {{- $styles = $styles | append (printf "--param-table-image-height: %s" .) -}} {{- end -}} {{- with $marginLeft -}} {{- $styles = $styles | append (printf "--param-table-margin-left: %s" .) -}} {{- end -}} {{- $inner := trim .Inner "\n\r \t" -}} {{- /* Column count: "| a | b |" splits into 4 parts, so two columns. It is taken as the widest row rather than the first one -- Markdown drops every cell past what the delimiter row declares, so a narrow first row would silently swallow the content of all the others. */ -}} {{- $cols := 1 -}} {{- range (split $inner "\n") -}} {{- $line := trim . " \t\r" -}} {{- if ne $line "" -}} {{- $n := sub (len (split $line "|")) 2 -}} {{- if gt $n $cols -}}{{- $cols = $n -}}{{- end -}} {{- end -}} {{- end -}} {{- $header := "" -}} {{- $delim := "" -}} {{- range seq $cols -}} {{- $header = print $header "| " -}} {{- $delim = print $delim "| --- " -}} {{- end -}} {{- $header = print $header "|" -}} {{- $delim = print $delim "|" -}} {{- $html := $p.RenderString (dict "display" "block") (print $header "\n" $delim "\n" $inner) -}} {{- $html = replaceRE `(?s)` "" $html -}} {{- /* A trailing cell can carry an illustration. The table then has to opt out of the 36rem reading-width cap the theme puts on body tables, or the picture stops mid-page instead of reaching the right margin. */ -}} {{- $class := "table" -}} {{- if strings.Contains $html "" (printf `` $class) -}} {{- if not ($p.Scratch.Get "param-table-css") -}} {{- $p.Scratch.Set "param-table-css" true -}} {{- end -}}
