## Replies

**Aurélien Pierre** — 2024-06-06

Ansel/DT are hard-wired to save editing histories into the DB, so you need to import images into the DB no matter what. Both software can write sidecar XMP files, but those are only redundancies to share/sync editings in a portable way. The backbone is still the DB.
