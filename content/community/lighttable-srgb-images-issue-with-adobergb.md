*Posted by **Massimo** on 2024-02-24.*

Hi,

I'm using Ansel on Windows 10 and my monitor profile is generated by calibration software: color space is AdobeRGB.

In Lighttable module, jpeg images with embedded sRGB color profile look strongly oversaturated instead color reproduction is fine in Darkroom and Slideshow modules. Images with embedded AdobeRGB color profile are always correct.

In attachment two jpg images I've generated with Gimp to quickly detect visualization issues. The former has sRGB embedded color space, the latter has AdobeRGB: the leftmost two patches should look very similar in both images.

## Replies

**Massimo** — 2024-03-02

Hi again,

I've noticed that the issue happens when images have not yet been processed. For example, enabling exposure module in Darkroom (zero adjustment) fixes the issue in Lighttable.

---

**Aurélien Pierre** — 2024-03-09

Images that have not been processed display the JPEG thumnail embedded in the RAW file, which more likely are sRGB. Your issue would indicate that those JPEGs get slapped to display, in lighttable, without color management. Once you edit the files, the default thumbnail gets replaced by Ansel preview, which supports color management.
