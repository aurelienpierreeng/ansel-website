Is there a way to create and save a custom file opening history stack ?

Currently, I have to change many of the opening defaults for every file I process.

eg. these are the steps I take before even starting to process the image...

Highlight Reconstruction/Method:  Guided Laplacians

Lens Correction:  Turn Off

Exposure:  Turn Off or Set to 0

Filmic RGB/Options/Preserve Chrominance:  Set to No

Color Balance RGB:  Turn Off or Set all settings to 0

Color Balance:  Turn Off

Most of my picture files are of live music events with extreme dynamic range that always contain blown out highlights & lots of out of gamut colors
